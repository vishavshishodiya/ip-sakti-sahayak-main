## 🔧 Expand Your Knowledge Base

### Option 1: Add More Documents

1. Create a `data` folder:
```bash
mkdir data
```

2. Add markdown files:
```
data/
├── ayush_guidelines.md
├── patent_laws.md
├── tkdl_info.md
└── regulatory_framework.md
```

3. Rebuild:
```bash
python build_knowledge_base.py
```

### Option 2: Enable Web Scraping

Edit `build_knowledge_base.py` and uncomment the scraping section (line 41-48):

```python
# Uncomment these lines:
print("     Scraping web content (may take 2-3 minutes)...")
try:
    documents = scrape_sample_ayurveda_content()
    pipeline = DocumentIngestionPipeline(rag)
    result = pipeline.ingest_scraped_data()
    print(f"     SUCCESS: Added {result['chunks_added']} chunks from web\n")
except Exception as e:
    print(f"     WARNING: Scraping failed - {str(e)}\n")
```

Then run:
```bash
python build_knowledge_base.py
```

### Option 3: Custom Web Scraping

Edit `web_scraper.py` to add your own sources:

```python
def scrape_custom_source(self):
    urls = [
        'https://your-source.com/ayurveda-content',
        'https://another-source.com/patents'
    ]
    
    for url in urls:
        doc = self.scrape_url(url)
        if doc:
            doc['category'] = 'Your Category'
            self.save_document(doc)
```

2. **Upload Document** (POST /ingest/upload)
